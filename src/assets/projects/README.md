- `triptyque.svg`
- `mya.svg`
- `roma.svg`
- `maker-week.svg`
- `no-sense.svg`
- `tarots-oracles.svg`
- `croisiere-danse.svg`
- `snatsh.svg`
- `projet-x.svg`

`src/app/components/projects-section.tsx`.
